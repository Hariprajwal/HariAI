# Contributing to HariAI

Thank you for helping improve HariAI. The project is a research prototype;
reproducible measurements and clear limitations are particularly valuable.

1. Check existing issues and discuss substantial changes before implementing them.
2. Install with `python -m pip install -e .` and run
   `python -m unittest discover tests`.
3. Keep model checkpoints, personal memories, credentials and downloaded
   datasets out of commits. Document dataset provenance and applicable terms.
4. Report experiment settings, exact model sizes, held-out results and failures.
   Do not claim that generated code or proofs were verified without a real,
   appropriate verification process.
5. Submit a pull request describing the change, its motivation and validation.

The current software license is [LICENSE](LICENSE). Commercial use requires a
separate written agreement with the copyright holder. Please do not submit code
or data you lack rights to contribute.
